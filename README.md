# 繼承系統表產生器（本機離線安全版）

專為台灣實務繼承登記設計的「繼承系統表」產生器，支援傳統直豎括號連線、配偶與多代直系血親輸入、產出後點擊圖表直接修改，並可匯出 **Excel (`.xlsx`)**、**PNG 圖片**、**PDF 列印** 與 **JSON 專案檔**。

## 🛡️ 資料安全與隱私聲明
- **100% 本機端運算**：所有輸入之姓名、出生／死亡年月日與備註資料，僅在您目前的電腦瀏覽器記憶體中處理，**絕不會上傳至網路或任何外部伺服器**。
- **無外部依賴 & 嚴格 CSP**：已移除所有外部 CDN 腳本，並啟用 `Content-Security-Policy (connect-src 'none')` 強制封鎖對外連線。
- **共用電腦保護**：支援一鍵關閉「自動暫存於本機瀏覽器」與「🗑️ 清除本機暫存」。

## ✨ 主要功能
- 支援被繼承人、多位配偶、多代繼承人（長子、次子、代位繼承等）逐一輸入與拖曳／上下調整順序
- 支援民國年與西元日曆自動換算
- 支援**深色模式／淺色模式**切換
- 支援**匯出 Excel (`.xlsx`)**（內含「繼承系統表」樹狀排版與「繼承人明細清單」雙工作表）
- 支援**下載高解析度 PNG** 與**列印／另存 PDF**
